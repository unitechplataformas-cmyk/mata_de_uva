# Convención tipográfica Mata de Uva V2

- Los títulos editoriales usan `--font-editorial`, respaldada por Cormorant Garamond.
- Los párrafos y descripciones usan `--font-copy`, cuyo nombre CSS real es `neue-haas-grotesk-display` y se carga desde Adobe Fonts (`https://use.typekit.net/afl1mcy.css`).
- La copia descriptiva de referencia usa peso 400, interlineado 1.4 y `letter-spacing: 0`; los tamaños específicos de cada sección se conservan cuando forman parte del mockup aprobado.
- Los títulos manuscritos aprobados como imágenes (por ejemplo, `assets/historia-white.png` y `assets/visita.png`) no se sustituyen por fuentes.
- La sección `La historia / APENAS COMIENZA` está aprobada: no cambiar sus tipografías, tamaños, colores, espaciados, botellas ni distribución sin una solicitud explícita.
- Los botones pueden conservar su tipografía editorial propia cuando el mockup lo indique.
